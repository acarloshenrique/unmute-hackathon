# unmute-demo-pitch

1. Use docs/DEMO-PITCH.md. Reserve os primeiros segundos para mostrar valor e a voz real; nomeie o papel da Agora sem fazer uma aula de arquitetura.
2. Grave áudio do usuário e do agente. Faça um teste curto, desligue notificações e oculte credenciais.
3. Mostre uma correção por voz com resultado visível. Deixe claro o que foi simulado e o que funcionou na gravação.
4. Confira duração, link sem login e uma cópia de backup. Use dados e vozes que o time tem autorização para divulgar.
