## Ordem recomendada

1. **Prova técnica**: microfone → sessão real na Agora → resposta audível → encerrar.
2. **Fluxo principal**: uma tarefa com resultado visível, validação do estado e recuperação de erro.
3. **Diferencial de voz**: interromper e corrigir um dado; a mudança deve aparecer uma única vez.
4. **Validação**: rodar `TESTES-VOZ.md`, gravar a melhor versão funcional, preparar pitch.
5. **Fechamento**: a partir de 10h30 de domingo, alvo interno para congelar alterações, checar acesso anônimo, subir e revisar a entrega com antecedência.

Critério para cortar escopo: se uma funcionalidade não melhora a interação de voz, não comprova a integração ou não torna a demo mais clara, deixe para depois.
