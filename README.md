# UNMUTE by Agora | Kit de partida

Este kit ajuda o time a construir e entregar. Ainda não é uma aplicação nem uma submissão. Nenhuma credencial, integração ativa ou repositório remoto vem no pacote.

## Comece aqui

1. Se você vai clonar o repo do time, **clone primeiro** e só depois copie este kit. O Git não clona por cima de uma pasta preenchida. Se já houver arquivos com o mesmo nome, compare antes de substituir.
2. Abra a pasta no Codex. Leia `AGENTS.md` e `docs/PLANO.md`. Use, por exemplo: “Leia a skill `unmute-agora-voz` e me ajude a subir o starter oficial sem expor credenciais”.
3. Confirme o acesso à Agora e faça um teste real de microfone → agente → áudio antes de adicionar funcionalidades.
4. Escolha um público, um problema e um fluxo demonstrável. Registre a decisão no plano.
5. Antes de entregar, use `docs/ENTREGA.md` e `docs/README-PROJETO.md`. Substitua este README pelo texto final com instruções reproduzíveis.

## O que vem junto

- **8 skills do hackathon + 1 skill oficial da Agora** em `.agents/skills`: escopo, integração, design de voz, implementação, testes, segurança/publicação, demo e submissão.
- **Ferramentas**: guia Windows, instalação opcional do CLI da Agora e um check local de prontidão em PowerShell.
- **Entrega**: plano de execução, casos de teste, roteiro de demo, checklist, modelo de README e registro de componentes externos.

Se a sua ferramenta não carregar automaticamente as skills, peça que ela leia o arquivo `SKILL.md` desejado. Nada exige instalar o kit globalmente.
